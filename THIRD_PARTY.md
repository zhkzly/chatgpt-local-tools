# Upstream projects

Original code, examples and documentation here are MIT licensed. No third-party
binary, vendor Skill or installer is copied into this repository.

- [OpenAI tunnel-client](https://github.com/openai/tunnel-client), Apache-2.0:
  downloaded separately from the official v0.0.20 Linux full-client release.
  The checked archive hashes are in `connect.py`. Keep the upstream license
  applicable to that separately installed executable. Official lifecycle/Skill
  documentation is linked, not redistributed as our own work.
- [KDocs official Skill/CLI](https://github.com/kdocs-app/kdocs-skill): only original
  wrapper configuration and links are included. Follow upstream terms and install
  from the official source; do not assume this repository's license covers it.
- [WPS365 CLI](https://github.com/wps365-open/cli): linked native MCP integration.
- [LLM Wiki](https://github.com/nashsu/llm_wiki): existing installed MCP is invoked;
  neither application source nor knowledge-base contents are bundled.
- [Model Context Protocol](https://modelcontextprotocol.io/): the adapter implements
  a deliberately narrow tools-only initialization-based stdio protocol.

OpenAI, ChatGPT, WPS and KDocs names identify interoperability targets, not
endorsement or ownership of this independent project.
